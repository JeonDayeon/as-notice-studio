# 안내문 스튜디오

아일랜드 식탁 무선충전 제품의 안내문을 담당자가 직접 수정하는 서식형 편집기입니다. 고객 접수·방문 일정 관리 기능은 포함하지 않습니다.

## 블록 구성 사용 방법

- **새 안내문:** `+`를 누르면 빈 화면에서 시작합니다. 기존 안내문은 별도 문서로 보존됩니다.
- **큰 틀:** `문서 · 디자인 설정`에서 안내 구역을 추가하고 한 줄에 1~4개 구역을 배치할 수 있습니다. 구역은 3개로 제한되지 않으며 더 많으면 다음 줄로 이어집니다.
- **블록 먼저 만들기:** `내 블록 보관함 · 만들기`에서 사진+글, 사진 두 장, 설명, 체크리스트, Q&A, 강조 안내, 빈 칸 중 하나를 선택합니다.
- **칸 구성:** 블록 작업창에서 행을 추가하고 한 줄을 1~6칸으로 나눕니다. 칸의 비율·간격·정렬을 설정하고 글·사진·아이콘·도형을 넣습니다. 그림판처럼 좌표를 지정하는 방식은 아닙니다.
- **위치:** 칸 안에서 내용의 위·아래 순서와 가로·세로 정렬을 설정하고, `다른 칸으로 옮기기`로 내용을 이동합니다.
- **디자인:** `색상 · 선 · 효과`에서 블록 전체, 선택한 칸, 선택한 요소를 골라 단색·그라데이션 채우기와 선, 투명도, 블러를 설정합니다.
- **아이콘·이모지:** 기본 아이콘을 선택하거나 이모지를 입력합니다. 기존 FAQ·강조 안내도 별도의 칸 구성 변환 없이 아이콘을 바꿀 수 있습니다.
- **보관과 재사용:** 만든 블록을 보관함에 저장하거나, `큰 틀에 넣기`로 원하는 안내 구역에 배치합니다. 기존 블록에서도 `내 블록으로 저장`할 수 있습니다.
- **기존 모양 유지:** 기존 안내문의 기본 3단 비율·사진·문구는 그대로 시작합니다. 해당 블록의 `칸 구성 · 디자인 설정`을 직접 눌렀을 때만 내부 배치 편집으로 전환됩니다.

## 문구 수정 및 출력

1. 미리보기의 네모 칸 또는 왼쪽 항목을 누릅니다.
2. 오른쪽에서 제목·설명·사진을 바꿉니다. 설명을 한 줄씩 쓰면 목록 항목으로 나뉩니다.
3. 위쪽에서 `한 장으로`, `리셋 안내`, `LED 안내`, `Q&A` 중 출력할 범위를 선택합니다.
4. `이미지 저장`으로 PNG를 저장합니다. 노션용은 5MB 미만으로 크기를 자동 조절합니다.
5. `PDF · 인쇄`에서 PDF 파일을 바로 저장하거나 인쇄창을 열어 프린터를 선택합니다.
6. `편집본 저장`으로 문구·사진·칸 구성·효과·내 블록이 포함된 파일을 보관합니다. 다른 PC에서 `불러오기`로 다시 수정할 수 있습니다.

위쪽 `+`는 새 안내문을 만들고, 왼쪽 `현재 안내문 복사`는 기존 안내문을 복사합니다. 기본 서식으로 복원하거나 항목을 삭제했을 때는 위쪽 되돌리기 버튼으로 복구할 수 있습니다. 안내문 문서 전체 삭제는 파일 백업 후 진행하세요.

자동 저장은 현재 브라우저에만 보관됩니다. 브라우저 데이터를 삭제하거나 다른 PC로 옮길 때를 대비해 편집본 파일도 보관해 주세요. 이 버전에는 직원 간 공용 저장과 로그인 기능이 없습니다.

## 실행

- 권장: 아래 방법으로 GitHub Pages에 올려 웹주소로 접속합니다.
- 로컬: `index.html`을 Chrome 또는 Edge로 엽니다. 브라우저 설정에 따라 로컬 파일 저장·글꼴 동작이 다를 수 있습니다.
- Node.js가 있는 PC에서는 이 폴더에서 `npm run dev` 후 표시되는 주소로 접속할 수 있습니다. 외부 패키지 설치는 필요하지 않습니다.

## GitHub Pages 게시

1. GitHub 저장소를 만듭니다.
2. 이 폴더 안의 `index.html`, `styles.css`, `app.js`, `renderer.js`, `exporters.js`, `defaults.js`, `grid-layout.js`, `grid-validation.js`, `grid-editor.js`, `grid-editor.css`, `assets/`, `.nojekyll`을 저장소 최상위에 올립니다. 파일이 아니라 이 폴더 전체를 한 단계 더 넣지 않도록 확인합니다.
3. 저장소 Settings → Pages → Deploy from a branch를 선택합니다.
4. `main`, `/ (root)`를 선택해 저장합니다.
5. 생성된 Pages 주소로 접속합니다. 서버 프로그램이나 비밀 키가 필요하지 않습니다.

공개 Pages 주소는 누구나 접근할 수 있으므로 고객 정보는 이 안내문에 입력하지 않습니다. 고객 설문·방문 일정·개인정보는 추후 별도 AS 전산에서 관리하도록 분리합니다. 회사 공용 저장 기능이 필요하면 별도 서버 저장을 연동합니다.

## 서식과 사진

- 기본 서식은 리셋 안내, LED 안내, FAQ의 세 영역입니다. 영역·블록·사진의 개수는 3개로 제한하지 않습니다.
- 제목·본문·사진·리셋 단계·강조 안내를 수정하고 추가·삭제·순서 이동할 수 있습니다.
- 글꼴·색상·들여쓰기와 자동 줄바꿈은 서식이 관리합니다. 자유 드래그 편집 대신 고정된 칸을 채우는 방식입니다.
- 글자가 길어지면 카드와 이미지 높이가 함께 늘어납니다. 인쇄는 현재 범위를 한 장에 맞추므로 긴 안내문은 개별 범위로 나누어 출력하면 읽기 쉽습니다.
- 제품·설치 사진은 제공된 예시 이미지에서 추출했습니다. 대표 제품 사진은 저해상도이므로 사진 칸에서 원본 사진으로 바꾸면 출력 품질이 좋아집니다.
- 초기 문구와 출력 수치는 제공된 자료를 옮긴 예시입니다. 배포 전 해당 제품의 사양과 회사의 AS 처리 기준에 맞게 확정하세요.
- Noto Sans KR 글꼴을 함께 포함하며 글꼴 라이선스는 `assets/OFL.txt`입니다.

## 향후 전산 연동

편집본은 `schemaVersion: 2`의 JSON(기존 버전 1 파일도 불러오기 가능)으로 문구·서식·사진·칸 구조·효과·블록 보관함을 보관합니다. AS 고객 접수 데이터와는 분리되어 있습니다. 현재의 `model.document.sections[].blocks[]` 구조를 이후 전산프로그램의 안내문 템플릿 저장 기능과 연결할 수 있습니다.

추가 가능 항목: 회사 공용 템플릿, 수정 이력, 담당자 권한, 안내문 승인, 고객별 안내 링크 발송.

## 파일 구성

`defaults.js`: 기본 문구·예시 사진 / `renderer.js`: 미리보기·출력 공통 도형과 효과 / `grid-layout.js`: 블록 서식 / `grid-editor.js`: 칸 설정 화면 / `grid-validation.js`: 편집본 구조 확인 / `exporters.js`: PDF 출력 / `app.js`: 편집·저장 / `styles.css`: 화면·인쇄 서식.

## 너비·그라데이션·삭제

- 왼쪽 구역 이름 또는 블록을 눌러 `너비 · 큰 틀의 자리`에서 1칸·여러 칸·한 줄 전체 너비를 고릅니다. `새 줄에서 시작`으로 줄바꿈을 지정할 수 있습니다.
- 블록 하나만 넓히려면 `↔ 이 블록을 한 줄 전체로`를 누릅니다. 필요하면 문서 설정에서 해당 구역 순서를 바꾸어 중간에 배치합니다.
- `칸 구성 · 색상 · 그라데이션`으로 디자인을 열고 상단의 `◐ 그라데이션 · 색상`을 누릅니다. 디자인 대상(블록·칸·요소)을 고른 뒤 채우기 또는 선을 그라데이션으로 바꾸고 두 색상과 방향을 지정합니다.
- 블록 삭제는 왼쪽 목록의 `삭제` 또는 오른쪽 상단 `블록 삭제`입니다. 위쪽 되돌리기로 복구할 수 있습니다.
- 보관함에서 삭제한 블록은 보관함 하단 `삭제한 보관 블록 · 복구`에서 복구합니다.


## PDF·이미지 가져오기 (2.2 시험 기능)

- 왼쪽 `서식에서 시작`에서 기존 3단 종합형 또는 PDF를 바탕으로 추가한 가로 5단계 리셋 서식을 선택합니다. 새 안내문으로 추가하며 글·사진·칸 구성은 각각 수정할 수 있습니다.
- `PDF · 이미지 가져오기`에 25MB 이하 PDF(최대 5쪽), PNG, JPG, WebP를 넣으면 글상자를 자동 인식하고 사진 후보 영역을 찾습니다. 미리보기를 확인한 뒤 새 안내문으로 추가합니다.
- 가져온 페이지는 원본 배치를 유지합니다. 수정 전의 글·사진·도형은 원본과 동일하게 표시되고, 수정한 글상자 또는 교체한 사진 후보 영역에만 변경이 적용됩니다. 원본 이미지 위에 편집 영역을 겹치는 방식이며 행·칸 구조 전체를 자동 재설계하는 기능은 아닙니다.
- 글상자를 눌러 인식 결과를 원본과 대조해 수정하고 확인 완료로 표시합니다. 사진 후보는 실제 사진 경계와 다를 수 있으므로 확인 후 교체합니다. 잘못 잡힌 영역은 인식에서 제외할 수 있고, 되돌리기 및 원본 복원이 가능합니다.
- 저해상도·장식 글꼴·사진 속 문자는 인식 오류가 생길 수 있습니다. 모든 인식 문구를 확인해 사용합니다. 글이 길어지면 고정된 원본 상자 안에서 글자 크기를 줄입니다.
- 파일 내용은 브라우저 안에서 처리하며 외부 인식 서버에 업로드하지 않습니다. PDF.js 4.10.38, Tesseract.js 6.0.1 및 한글·영문 인식 데이터를 공개 CDN에서 받으므로 첫 사용과 새 기기에서는 인터넷 연결이 필요합니다. 이 기능은 완전한 오프라인 실행을 지원하지 않습니다.
- 편집본 JSON에는 원본 페이지 이미지, 인식 영역, 수정 글·사진과 확인 상태를 함께 저장합니다. 여러 쪽은 출력 범위에서 쪽별로 선택할 수 있습니다.

저장소 최상위의 `index.html`은 글꼴·기본 서식·사진을 포함한 실행용 단일 파일입니다. 분리된 개발 소스는 `source.zip`을 풉니다. 소스의 `templates.js`는 등록된 서식, `reference-import.js`는 파일 인식과 가져온 페이지 편집을 담당합니다.
